A warm, editorial block theme for small studios, freelancers and writers.

== Description ==

Fieldnote is a full site editing (block) theme built entirely with theme.json, HTML templates, template parts and block patterns. It includes bundled variable fonts, a fluid type scale, four style variations, four section styles and a library of ready-to-use patterns, including a complete landing page.

Everything can be customized from Appearance > Editor without writing code.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New.
2. Click Upload Theme and choose the theme zip file.
3. Click Install Now, then Activate.
4. Go to Appearance > Editor to customize your site.

== Frequently Asked Questions ==

= How do I build the home page shown in the screenshot? =

Create a new page and choose the "Landing page" pattern from the pattern modal. In the page settings, select the "Landing Page (no title)" template. Then set it as your homepage under Settings > Reading.

= How do I change a colored section? =

Select the Group block, open the Styles tab in the block sidebar and pick Ink, Clay, Sage or Paper.
